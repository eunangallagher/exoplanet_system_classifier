# Exoplanet System Classifier
CT4101 Machine Learning Portfolio Project.
This project will investigate if machine learning models can predict 
whether a multi-planet or single-planet system orbits a star.

## How to set up project and run it
1. Clone or download this folder
2. Open terminal in root directory of this folder
3. Run "pip install -r requirements.txt" to install packages
4. Run "python preprocessing.py" to run source code
